# ADR-0001: Record architecture decisions

- **Status:** Accepted
- **Date:** 2026-11-26

## Context
The POC changed direction several times (document → request-centric → audio). The reasons behind choices were only in chat history.

## Decision
Record significant decisions as ADRs in `docs/adr/`, one file per decision, numbered, in the format *Context / Decision / Consequences (+ Alternatives)*. Accepted ADRs are not edited except for status; changes are made by a superseding ADR.

## Consequences
+ Rationale survives people and context loss. − Small writing overhead per decision.
